# Infrastructure Investment Model

## Overview
This repository contains an illustrative infrastructure investment model developed independently to demonstrate financial modelling capability. The model evaluates long‑term operating performance, cash flows, leverage, valuation outcomes and risk‑adjusted returns using publicly available information and simplified assumptions.

## Model Purpose
The model showcases core skills in infrastructure and renewable‑energy investment analysis, including cash‑flow construction, scenario modelling, valuation techniques and risk diagnostics. It is intended for recruitment and portfolio demonstration.

## What the Model Does
- Builds operating, financing and equity cash flows over a 20‑year horizon  
- Assesses valuation using DCF and exit‑multiple approaches  
- Models downside, base and upside scenarios with probability weighting  
- Produces IRR, MOIC, NPV and enterprise‑value outputs  
- Includes risk metrics such as expected return, VaR proxy and probability of loss  
- Provides a transparent structure with inputs, checks and source references

## Structure
The model is organised into clear, auditable tabs:
- **Inputs** – editable operating, financing and valuation assumptions  
- **Asset_Model** – cash‑flow engine and debt schedule  
- **Valuation** – DCF, exit multiple and blended valuation outputs  
- **Scenarios_Risk** – scenario analysis and risk metrics  
- **Checks** – validation of assumptions, capital structure and model integrity  
- **Sources** – public references and assumption log

## Disclaimer
This model is an illustrative analytical exercise and not investment advice. All inputs are based on public information, estimates and simplifying assumptions that may be incomplete or outdated. Outputs are sensitive to market conditions, financing terms and asset‑life assumptions and should not be relied upon without independent verification.
